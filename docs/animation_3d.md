## 3Dの開き方・操作

`atmosphere_3d.html` をブラウザで開く。データと描画コードを1ファイルへ埋め込んでおり、CDN、追加ライブラリ、外部通信、サーバーは不要。約10 MBあるので、メール等で移動する際は添付サイズに注意する。スマホではファイルを端末へコピーし、JavaScriptが実行できるブラウザで開く（OSのファイルプレビューや一部アプリ内プレビューはJavaScriptを実行しない場合がある）。

| 操作 | 動作 |
|---|---|
| マウス／指1本でドラッグ | 左右回転・仰角変更 |
| ホイール／指2本のピンチ | ズーム |
| 矢印キー、+、− | キーボードで視点操作 |
| 気象要素ボタン | 気温、湿度、風、雲水、雲氷、雲量、鉛直流、気圧を切替 |
| 再生・停止、‹、›、時刻スライダー | 時刻を選択・アニメーション表示 |
| 下限・上限高度 | 海抜高度帯を選択。狭くすると層ごとの分布を見やすい |
| 表示しきい値 | 微量の雲などを非表示。Wでは絶対値のしきい値 |
| 大気の不透明度 | 点群の透過度を変更（物理的な光学的厚さではない） |
| 高さの強調 | 鉛直方向だけ1〜5倍。表示値の高度は変わらない |
| 点にマウスを合わせる／タップ | 値、単位、海抜高度、緯度経度を表示 |
| 視点を戻す | 回転とズームを初期状態へ戻す |

既定はCLDFRA。地形は元のHGT（1 km格子）で、表示範囲は主解析半径20 kmに入る格子の外接矩形。東西南北の座標は中心付近の局所接平面で近似し、東・北をkmで表す。点群は大気の実際のモデル層であり、高度面へ補間した等値面ではない。風は東西・南北・鉛直成分を持つ瞬間ベクトルで、流跡線ではない。最大高度は既定で海抜15 km、地形の下からは見上げられないよう仰角を制限する。

## 作成コマンド

プロジェクトのディレクトリで実行する。CASEは実際のケースフォルダへ置換する。

```bash
# 2D + 3Dの不足分を作成
./scripts/animate_weather_case.sh output/old

# 3Dだけ
./scripts/animate_weather_case.sh output/old --dimension 3d

# 2Dだけ
./scripts/animate_weather_case.sh output/old --dimension 2d

# 3Dを軽量に作り直す（元のWRF出力は変更しない）
./scripts/animate_weather_case.sh output/old --dimension 3d --force \
  --horizontal-stride 5 --vertical-stride 3 --time-stride 2 --max-height-km 12
```

3D既定は水平3格子、鉛直2層ごと、時刻1コマごと。今回22層×13×13=3718点/時刻、全49時刻。時刻を間引いても最後の時刻は含める。再生成には `--force` が必要。`atmosphere_3d.json` に範囲、表示間隔、全時刻のスケール、ファイル容量を保存する。入力に必須3D変数がない場合は、3D作成で不足名を含むエラーを返す。

WRFの新規実行時も動画生成が有効なら2Dと3Dを作成する。`--no-animation` 指定時は生成しない。3Dの表示密度を変えたい場合は、完走後に上記コマンドを使う。

## 気象量の定義

WRFの出力は摂動量とずれた格子を含むため、以下の変換を行う。[WRF公式の変数定義](https://www2.mmm.ucar.edu/wrf/users/wrf_users_guide/build/html/output.html)

- 気温：`(T + 300) × ((P + PB) / 100000)^(Rd/Cp) − 273.15`（℃）。Tをそのまま気温として扱わない。
- 高度：`(PH + PHB) / g` の上下界面平均（海抜km）。層厚は界面高度の差。
- 風：U、V、Wをそれぞれのずれた格子から隣接平均で質量格子へ変換し、U・VはCOSALPHA・SINALPHAで東西・南北へ回転。Wは上向きが正。風速は3成分の合成。
- 湿度：QVAPOR（混合比）から `e = r p / (0.622 + r)` で水蒸気圧を求め、液水に対する飽和水蒸気圧で割る。氷に対する相対湿度ではない。表示は0〜100%へ制限する。
- QCLOUD、QICE：乾燥空気に対する混合比をkg/kgからg/kgへ変換。CLDFRAは0〜1から%へ変換。

### 2D雲量

CLDFRAを鉛直に重ねる「最大ランダム重なり」の診断値。連続する雲層は最大重なり（最大の雲量）、雲のない層で離れた雲群はランダム重なり `1 − ∏(1 − 雲群の雲量)` とする。総雲量は全モデル層を対象とし、地表付近の霧も含める。

下層は地上300〜2000 m、中層は2000〜6000 m、上層は6000 m以上。区切りはWRF-Pythonの既定高度区分を参考にするが、同ライブラリのRHからの雲量推定とは異なり、保存されたCLDFRAを直接使う。該当するモデル層がない帯や欠測を含む帯は欠測とし、晴天0%と区別する。[高度区分の参考](https://wrf-python.readthedocs.io/en/develop/internal_api/generated/wrf.g_cloudfrac.get_cloudfrac.html)

これは重なりの仮定を伴う鉛直雲量であり、観測された総雲量や雲の光学的厚さそのものではない。雲量100%でも短波放射が0になることを意味しない。

### 雲水・雲氷の鉛直積算量

`Σ(混合比 × 乾燥空気密度 × 層厚)`（kg/m²）。乾燥空気密度は全圧・気温・水蒸気混合比から計算し、混合比の分母を一致させる。QCLOUDには雨水を、QICEには雪・霰を含めない。2Dの積算は全モデル層・全水平格子で行い、3D表示の間引きは適用しない。
