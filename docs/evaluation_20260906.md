# FDDA完走結果の評価と改善（2026-09-06）

今回はFDDAが有効な状態で完走し、気温と風は大きく改善した。ただし学校の気圧は悪化し、水蒸気不足と降水不足も残る。全変数の精度改善や、別事例への汎化が確認できたわけではない。今回実行したのは既存出力の解析とPythonテストのみであり、WRF・real・WPSは起動していない。

## 比較条件と実行確認

- 最新：`output/case_20260904T1200_20260904T2000`。比較元：`output/old`。
- 旧・新モデルの両方を、最新ケース内の同一 `observations/observations.csv` で再評価した。観測元データは変更していない。
- 2026-09-04 12:00〜20:00 JST、spin-upを除いたd03の49時刻。学校の積算差分降水だけは先行観測がない最初の区間を除いた48時刻。
- `case.json`、`namelist.input`、rslでFDDAを確認。3領域で風・温度・水蒸気のナッジングが実際に適用され、WRF成功終了を記録した。
- 計算終了は20:00:36 JST。d01の54秒刻みの終端超過であり、解析終端20:00までのd03出力は存在する。
- 格子9/3/1 km、45層、時間刻み54/18/6秒、spin-up 6時間。MSM由来の3時間間隔場への拘束で、学校観測の直接同化ではない。

## 観測精度

RHの誤差の単位は百分率の「ポイント」。学校の風の観測高度・設置環境、格子と点の代表性差は残る。

| 項目 | 学校 旧RMSE → 新RMSE | 府中 旧RMSE → 新RMSE |
|---|---:|---:|
| 気温（℃） | 5.151 → **1.416** | 5.548 → **1.471** |
| 相対湿度（ポイント） | 21.854 → **9.275** | 32.772 → **18.489** |
| 風速（m/s） | 1.710 → **0.826** | 2.207 → **0.501** |
| 地表気圧（hPa） | 0.971 → **2.033** | 観測なし |
| 10分降水量（mm） | 0.0482 → **0.0513** | 0.1371 → **0.1358** |

気温RMSEは学校72.5%、府中73.5%低下した。最新の気温Biasは学校+1.240℃、府中+1.397℃で、暖偏差は縮小したが残る。最新の湿度Biasは−8.273、−18.095ポイント、風速Biasは−0.245、+0.288 m/s。

学校の気圧Biasは+0.879→+1.991 hPaへ悪化した。学校標高は現在の観測CSVでは未確定、モデル標高は81.08 m。気圧の校正・観測高度・海面更正の有無も確認材料であり、未確認の標高補正は加えていない。温度拘束に伴う鉛直構造・力学応答も候補だが、今回の比較だけで原因は断定できない。温度係数をさらに強める変更は見送った。

学校では、瞬間の降水強度とWRF区間平均を比較すると代表性が一致しない。そのため学校積算雨量の同一10分区間の差分を新たに採用した。最新の48区間合計はモデル約1.013 mm、観測1.990 mmで不足する。瞬間強度比較も従来どおり出力するが、降水の主判定には積算差分を使う。府中の改善は約0.9%にとどまる。

## 湿度の原因診断

気温とRHが同じ観測時刻に対応する組のみで、水蒸気圧・露点を計算した。モデルの水蒸気圧を保ったまま観測気温に置いた場合のRHを診断量とし、RH誤差を温度成分と水蒸気成分へ分解する。これは観測を使用する事後診断であり、予報値を補正した結果として精度表に混ぜない。

| 診断 | 学校 | 府中 |
|---|---:|---:|
| 旧 → 新の露点Bias（℃） | −0.638 → −0.721 | −2.513 → −2.512 |
| 新RH誤差の温度成分（ポイント） | −4.981 | −5.803 |
| 新RH誤差の水蒸気成分（ポイント） | −3.292 | −12.292 |

RHが改善した主因は冷却で、水蒸気不足そのものはほぼ改善していない。実際、学校のQ2期間平均は0.01360→0.01351 kg/kg、府中は0.01357→0.01355 kg/kgとほぼ同じ。府中ではとくに水蒸気不足が大きい。

現在の水蒸気係数1e−5 s⁻¹の単純な緩和時間は27.8時間で、14時間の積分期間に対して弱い。学校付近の入力met_emの12時JST地表RHは約85.1%で、モデル期間平均の約66.6%より湿潤。ただし時刻・物理場が異なるため、この値だけで効果は保証できない。

都市格子の学校では潜熱フラックス期間平均が1.84→1.37 W/m²と小さく、顕熱は103.3→126.1 W/m²。大気拘束によって気温は下がったが、地表面の熱・水収支の問題まで解消したとは言えない。土壌水分の単純な増加や土地利用の書換えは根拠不足なので行っていない。

d01の `Timing for main` を合計し、内包されるd02/d03の時間は重複加算していない。これは入力準備・初期化・動画生成を含む全工程の壁時計時間ではない。1回ずつの計測なので端末の負荷差を含む。親領域60分出力とThompson参照表の再利用が適用され、3表とも読込ログを確認した。今回の比較では積分ステップ数は同じであり、計算量の半減とは扱わない。

格子・鉛直層・spin-upを減らす追加高速化は、今回残った精度課題との両立が確認できないため採用していない。既存の観測格子限定読込と出力削減を維持する。追加した診断は地点時系列のみで処理し、3D全格子の追加読込や新規依存ライブラリは不要。

## 今回の変更と次の検証候補

1. `config/msm_guided.yaml` は今回改善を確認した既定設定として維持。
2. **未検証候補** `config/msm_guided_moisture.yaml` を追加。水蒸気係数だけを5e−5 s⁻¹（緩和時間5.56時間）へ変更した。既に有効な同じナッジング処理の係数変更であり、格子数・ステップ数・出力量は増えない。実際の時間差・精度差は未計測。
3. `evaluate-case` に `moisture_summary.csv` と地点別水蒸気診断CSVを追加。RHの見かけの改善と水蒸気の改善を区別する。
4. 学校積算雨量の正確な開始・終了時刻の差分を評価。欠測境界、区間中の欠測・リセットを除外し、補間で雨量を作らない。
5. 外部コマンドの開始・終了UTC、単調時計による経過秒、終了コードを `*.timing.json` に保存。次回から前処理とWRFの実時間を個別に検証できる。プロセスの失敗時ログ保存も維持する。

5e−5は今回の診断から選んだ感度実験値であり、WRF公式の推奨値や実証済みの最適値ではない。FDDAの変数・PBL内適用の仕様は [WRF公式namelist資料](https://www2.mmm.ucar.edu/wrf/users/wrf_users_guide/build/html/namelist_variables.html)、運用の前提は [WRF公式実行ガイド](https://www2.mmm.ucar.edu/wrf/users/wrf_users_guide/build/html/running_wrf.html) を参照。

次の実験を行う場合は別ケース名で保存し、今回の既定設定を対照とする。両地点の露点・RH・気温・風・降水と学校気圧を再比較し、乾燥偏差が減っても他変数を悪化させる場合は候補を既定へ昇格させない。別日時での検証も必要。この変更時点では起動していない。
