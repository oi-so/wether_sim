### 入力検査

`simulation/input_validation.py` に検査を分離した。海上の土壌欠測は許容する一方、大気のTT/RHは海上でも必須とする。

```python
soil, land_mask = xr.broadcast(dataset.ST, dataset.LANDSEA > 0.5)
land_values = soil.values[land_mask.values]
if not np.isfinite(land_values).all():
    raise ExternalCommandError("non-finite land soil temperature")
```

実装では温度範囲とLANDSEA自体の検査、全領域×全入力時刻のファイル存在確認も行う。今回18ファイルすべて成功。d02の後半入力にはRH=100.110%があり、わずかな過飽和・補間の超過を破損と混同しないよう、近地表RHは0〜110%を広い検査範囲とした。これは最適化パラメータや物理的な厳密上限ではない。入力RHをクリップしない。数値を改変せず、追加読込だけが増える。

### 2D風向

north = V10 * COSALPHA + U10 * SINALPHA

生のU10/V10は保存したまま、`eastward_wind_10m_ms` / `northward_wind_10m_ms` を追加し、静止画・2D動画で使用する。投影情報があるのに回転係数が欠ける入力は明示エラー。最小の非投影入力についてのみ従来の向きを仮定し、属性に仮定を記録する。[WRF公式サポートの回転式](https://forum.mmm.ucar.edu/threads/rotating-wrf-u-and-v-winds-before-and-after-reprojection.11788/)

今回d03全域の回転角は約±0.318°、学校は0°、府中は約−0.039°。今回の観測誤差への影響は小さく、暖偏差の原因ではない。ただし中心から遠い領域や別投影設定の風向に必要な修正。風速の計算は従来と同じで値を変えない。現在の風アニメーションと気温静止画を既存出力から再生成した。

### 係数と予測精度

気圧の高さ換算は次の式を使用し、計算はfloat64、|高度差|≤100 mに限定する。大きな高度差では鉛直プロファイルによる換算が必要。近地表のモデル仮温度を短い層の平均として用いる近似で、観測の気圧・気温は式へ入力しない。

```python
virtual_temperature = model_T2 * (1 + model_Q2 / 0.622) / (1 + model_Q2)
p_sensor = model_PSFC * np.exp(-9.80665 * (sensor_z - model_HGT)
                             / (287.05 * virtual_temperature))
```

高さ・種別・申告元は `config/station_metadata.yaml` とケース内 `observations/station_metadata.yaml` に保存し、評価の `pressure_sensor_height` 行と `station_metadata.json` へ記録する。メタデータがない場合や海面更正気圧の場合、この換算を適用しない。[NWSの静力学・層厚説明](https://www.weather.gov/source/zhu/ZHU_Training_Page/Miscellaneous/Heights_Thicknesses/thickness_temperature.htm)、[NWSの仮温度](https://www.weather.gov/epz/wxcalc_virtualtemperature)

```python
if not math.isfinite(nudging_moisture_s) or nudging_moisture_s < 0:
    raise ConfigurationError("nudging coefficient must be finite and non-negative")
```

水蒸気感度実験には既存 `config/msm_guided_moisture.yaml` を使用する。
